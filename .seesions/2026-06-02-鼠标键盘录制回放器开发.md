# 会话记录：鼠标键盘录制回放器开发
日期：2026-06-02

## 用户需求
做一个模拟键盘鼠标操作的功能：
1. 能记录一次所有的鼠标键盘操作，按时间维度复现
2. 使用 python 来做
3. 加入 qt 界面能有基本功能界面
4. 能指定窗口进行模拟记录好的鼠标操作
5. 最终交付成果：在桌面上能双击打开界面然后进行交互

## 技术选型
- Qt 框架：PySide6
- 打包方式：PyInstaller 单文件 exe
- 录制：pynput 全局 Hook
- 回放：SendInput (ctypes) + PyAutoGUI
- 窗口管理：pywin32

## 完成内容
1. 创建项目 MouseKeyboardRecorder
2. 实现 core/event_model.py - 事件数据结构和 JSON 序列化
3. 实现 core/window_manager.py - 窗口枚举、查找、激活、坐标转换
4. 实现 core/recorder.py - pynput 录制模块（鼠标节流、注入过滤）
5. 实现 core/replayer.py - 回放模块（SendInput、混合等待策略）
6. 实现 ui/window_selector.py - 窗口选择对话框
7. 实现 ui/main_window.py - 主窗口（录制控制、设置、事件表格）
8. 实现 main.py - 程序入口
9. 创建 build.bat、README.md、.experience、.task
