# 会话记录：鼠标键盘录制回放器开发
日期：2026-06-02

## 用户需求
做一个模拟键盘鼠标操作的功能：
1. 能记录一次所有的鼠标键盘操作，按时间维度复现
2. 使用 python 来做
3. 加入 qt 界面能有基本功能界面
4. 能指定窗口进行模拟记录好的鼠标操作
5. 最终交付成果：在桌面上能双击打开界面然后进行交互

## 技术选型
- Qt 框架：PySide6
- 打包方式：PyInstaller 单文件 exe
- 录制：pynput 全局 Hook
- 回放：SendInput (ctypes) + PyAutoGUI
- 窗口管理：pywin32
